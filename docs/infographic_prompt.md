# 인포그래픽 프롬프트 — ReMEmbR 프로젝트 전체 설명

> Canva AI(또는 디자이너)에게 붙여넣을 프로젝트 전체 개요.
> 맨 위는 "어떻게 디자인할지" 지시, 아래는 인포그래픽에 들어갈 실제 내용.

---

## 🎨 디자인 지시 (Canva에 줄 프롬프트)

로봇 AI 시스템을 설명하는 **세로형 인포그래픽 1장**을 만들어줘.

- **주제**: 로봇이 자기가 돌아다니며 본 것을 오래 기억하고, 자연어 질문에 답하는 AI "ReMEmbR"
- **톤**: 기술적·미니멀. 다크 배경(딥 네이비 `#0e1013`), 액센트 테크 블루(`#6ea8fe`) + 포인트 그린(`#5ec98a`)
- **위→아래 흐름**: (1) 제목/한 줄 소개 → (2) 문제 → (3) 2단계 동작(기억 만들기 / 질문 답하기) → (4) 핵심 기술 → (5) 평가 → (6) 우리의 기여(NPU 포팅) → (7) 한 줄 요약
- **핵심 시각 요소**: 가운데에 **2단계 흐름도**를 크게 — 왼쪽 "MEMORY BUILDING"(영상→기억), 오른쪽 "QUESTION ANSWERING"(질문→검색→답). 로봇이 돌아다니는 궤적 이미지 활용.
- **폰트**: 제목 굵은 산세리프 / 본문 가독 산세리프 / 숫자·코드 모노스페이스
- **아이콘**: 로봇, 카메라, 두뇌/기억, 데이터베이스, 말풍선(Q&A), 돋보기(검색), 지도·궤적, 칩

## 📋 인포그래픽 내용

### 1. 제목
**ReMEmbR**
로봇을 위한 장기 시공간 기억 & 추론 시스템
*(Long-Horizon Spatio-Temporal Memory for Robot Navigation — NVIDIA)*

### 2. 문제 (Why)
- 로봇이 몇 분~몇 시간 돌아다니면 **엄청난 양의 영상**이 쌓임
- 사람은 로봇에게 자연어로 묻고 싶음:
  *"가장 가까운 앉을 곳 어디야?" · "언제 건물 나갔어?" · "빨간 소화전 어디서 봤어?"*
- 영상 전체를 한 번에 LLM에 넣는 건 **너무 김** → 필요한 기억만 **똑똑하게 꺼내야** 함

### 3. 어떻게 동작하나 (핵심 2단계)

**① 기억 만들기 (주행 중)**
```
카메라 영상  →  VLM이 장면 캡션 생성  →  임베딩(1024차원)  →  벡터 DB에 저장
                "사람이 벤치 옆을 지나감"        각 기억 = 캡션 + 위치(x,y,z) + 시각
```

**② 질문에 답하기 (에이전트)**
```
질문  →  LLM 에이전트가 "무엇을 찾을지" 스스로 결정  →  기억 검색  →  답변
              ┌ 텍스트로 검색 (retrieve_from_text)
              ├ 위치로 검색   (retrieve_from_position)
              └ 시간으로 검색 (retrieve_from_time)
         에이전트가 여러 번 검색을 반복하며 필요한 기억을 모아 최종 답 생성
```
> 핵심 아이디어: LLM이 **툴을 써서 방대한 기억을 능동적으로 뒤진다** (전부 넣지 않고)

### 4. 핵심 기술 (구성 요소)
| 역할 | 기술 |
|---|---|
| 장면 이해 (VLM) | 영상 프레임 → 캡션 |
| 기억 저장 | 임베딩 + 벡터 DB(Milvus) — 텍스트·위치·시간으로 검색 가능 |
| 추론 (LLM 에이전트) | 검색 툴을 반복 호출해 답 도출 |
| 답 형식 | 위치[x,y,z] · 시간(분) · 예/아니오 · 서술 |

### 5. 평가 — NaVQA 벤치마크
- 실제 로봇 데이터(**CODa**) 기반 질문·답 데이터셋
- **7개 시퀀스 × 30문항 = 210 질문**
- 유형: 공간(where) · 시간(when/how long) · 서술(예/아니오·설명)
- 채점: 위치 **≤15m**, 시간 **≤2분** 이내면 정답

### 6. 우리의 기여 — NPU 포팅
> 원본은 **클라우드 GPT-4o + 대형 GPU**. 우리는 이걸 **소형 NPU 한 장**에 통째로 올림.

| | 원본 (NVIDIA) | 우리 (NPU 포트) |
|---|---|---|
| 캡션 VLM | VILA 1.5 **13B** (GPU) | **Qwen2.5-VL-3B** (NPU) |
| 추론 LLM | GPT-4o / 8B (클라우드) | **Llama-3.2-3B** (NPU) |
| 실행 위치 | 클라우드 + GPU | **로컬 NPU 1장** (12 GiB) |

**추가로 한 것**
- 소형 모델도 JSON 형식 안 깨지게 → **문법 강제 디코딩**
- 시간 계산은 LLM 대신 Python이 → **계산 툴 추가**
- GPS 없는 로봇 rosbag → **LiDAR로 궤적 복원**해 커스텀 데이터셋 생성

### 7. 왜 중요한가 (Impact)
- 클라우드 없이 **로봇 내부에서** 기억·추론 → 오프라인·저지연·프라이버시
- 손바닥만 한 칩으로 대형 모델 파이프라인을 대체
